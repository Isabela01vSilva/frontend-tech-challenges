
# Desafios Técnicos de Front-end

Este repositório reúne projetos desenvolvidos como parte de testes técnicos e desafios práticos de processos seletivos para vagas de Front-end.

O objetivo é documentar minhas soluções, demonstrar minhas habilidades técnicas e compartilhar projetos desenvolvidos ao longo da minha trajetória em tecnologia.

---
