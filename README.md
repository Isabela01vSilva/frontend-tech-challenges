
# 🚀 Desafios Técnicos de Front-end

Este repositório reúne projetos desenvolvidos como parte de testes técnicos e desafios práticos de processos seletivos para vagas de Front-end.

O objetivo é documentar minhas soluções, demonstrar minhas habilidades técnicas e compartilhar projetos desenvolvidos ao longo da minha trajetória em tecnologia.

## 🛠️ Tecnologias

- Angular
- TypeScript
- JavaScript
- HTML5
- CSS3 e SCSS
- APIs REST
- Design Responsivo

## 📂 Projetos

| Projeto | Empresa | Título do Desafio | Tecnologias |
|---|---|---| ---|
| [Desafio 01](./desafio-01) | Empresa de Hotelaria | Hotel Booking | Angular, TypeScript |
| [Desafio 02](./desafio-02) | Preço Justo | CRUD de Posts e Comentários | JavaScript, HTML, CSS |
| [Desafio 03](./desafio-03) | Marketdata Match | Decathlon Angular | Angular, SCSS |

## 🎯 Objetivo

Organizar e compartilhar soluções de desafios técnicos, demonstrando conhecimentos em desenvolvimento Front-end, resolução de problemas e boas práticas de programação.
